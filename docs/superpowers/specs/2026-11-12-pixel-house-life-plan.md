# 像素小屋：互動、養貓、賺錢花錢（計畫，討論用）

接在〈像素小屋主頁：計畫〉（2026-11-04）後面。那份做的是房間、家具、小人和商店；這份讓小屋「有事可做」。

## 目標

- 點他會有反應，他會留東西給你。
- 小屋裡可以賺金幣（現在小屋只能花）。
- 可以養一隻貓。
- 金幣有更多地方花，而且有會一直消耗的東西。
- **不比現在耗電、不比現在卡。** 這條跟上面四條一樣重，每一期都要量過才算完成（見「省電和流暢」）。

## 現在的狀況（寫計畫前先看過的）

| 項目 | 現在怎麼做 |
|---|---|
| 他做什麼 | 一次只有一個 `setTimeout`，20～40 秒後才挑下一件事（`useHouseResident.ts`） |
| 他走路 | CSS `transform` 的 transition，瀏覽器自己補中間的畫面，程式不逐格算 |
| 走路的腳 | 一個 110 毫秒的 `setInterval` 換圖。**他站著不動時這個計時器也在空轉**（不改畫面，但每秒醒來 9 次） |
| 切到背景 | `visibilitychange` 時計時器全停、他停下來 |
| 少走動 | 設定裡有，每件事做 4 倍久 |
| 蒸氣、Z、跳 | CSS 動畫，只動 `transform` 和 `opacity` |
| 錢 | `gameEconomy` 的 `global` 錢包；`payCoins()` 扣錢。小屋目前沒有賺錢的地方 |
| 價位 | 擺件 1,200～3,800、家具款式 800～2,000；刷盤子一天最多約 900 |
| 存檔 | `localStorage` 的 `pixel_house_state`，跟著備份走 |

底子是省電的，新功能照同一套做法就不會變重。

## 省電和流暢（每一期都要守的規則）

### 規則

1. **不新增一直跑的計時器。** 不加 `setInterval`、不加 `requestAnimationFrame` 迴圈。要等一段時間就用一次性的 `setTimeout`，跟他現在一樣。
2. **會隨時間變的數值不用計時器算。** 貓餓不餓、房間髒不髒、菜長好沒、打工賺多少，都只存「上次的時間」，打開小屋或回到前景時用「現在 − 上次」算一次。App 關著、在背景時完全不跑。
3. **畫面上會自己走的最多兩個**：他和一隻貓。貓的腳步跟他共用同一個換圖計時器。
4. **動畫只動 `transform` 和 `opacity`**，像素動畫用 `steps()`。不動 `top`/`left`/`width`，不用 `box-shadow`、`filter` 做動畫。
5. **看不到的房間不動。** 四間排成一條，只有畫面上那一間（滑動時加隔壁）的 CSS 動畫在跑，其他的暫停。
6. **不自動呼叫 AI。** 他頭上的話預設是寫好的句子；要用 AI 生的話只在使用者自己點的時候，而且一天有上限、可以關（這也是花使用者自己的 API 額度）。
7. **少寫存檔。** 只在「發生事情」時存（餵了、掃了、領了），不照時間存。新的資料放自己的 key（`pixel_house_life`），不跟擺設混在一起，存的時候不會觸發擺設那邊重讀。
8. **圖要小、要用到才載。** 貓、髒污、作物的圖進到那個功能才載，不拖慢打開小屋的時間。這整份計畫新增的圖合計不超過 1 MB（現在整個小屋 3.3 MB）。
9. **沿用「少走動」和系統的「減少動態效果」。** 開了之後貓也少走、氣泡不彈跳。
10. **切到背景全停**，包含貓和所有新加的一次性計時器。

### 先做的一件小事

把走路換圖的計時器改成「開始走才開、走到了就關」。現在他站著時也每秒醒來 9 次，貓加進來之前先修掉。

### 怎麼量（每一期做完都跑）

用無頭瀏覽器開小屋，量三段各 30 秒，跟做之前的數字比：

| 情境 | 量什麼 | 過關標準 |
|---|---|---|
| 放著不動（他站著） | 程式執行時間、版面重算次數 | 不比做之前多（修掉空轉後應該更少） |
| 他和貓都在走 | 同上，加上有沒有超過 50 毫秒的卡頓 | 沒有卡頓；程式執行時間比「只有他走」多不到三成 |
| 左右滑房間 | 掉格數 | 不比做之前多 |
| 打開小屋 | 到看得到房間的時間、載了多少圖 | 時間不變；沒用到的功能的圖沒被載 |

另外每一期都要在 CPU 放慢 4 倍的模式下滑一次、點一次，確認手感沒變。無頭瀏覽器量不到真機的耗電，**真機（特別是 Android）要你幫忙看一次**：開著小屋放 10 分鐘，手機有沒有變燙、電掉多少。

量出來沒過關，那一期就不算完成，先修再往下做。

## 分期

每一期做完都能單獨上線，不用等後面的。

### 第 0 期：打底

- 修掉走路計時器空轉。
- 寫量測的腳本，記下現在的數字當基準。
- 新的存檔 `pixel_house_life`（讀不到的欄位用預設值，跟現有的寫法一樣），確認有跟著備份走。
- `earnCoins()`：跟 `payCoins()` 成對，用同一個錢包，記帳的說明寫清楚來源。
- 「看不到的房間暫停動畫」。

### 第 1 期：點他有反應

- **點他**：點一下在他頭上冒出兩個小按鈕「聊天」「摸頭」，點別的地方或 3 秒後收起來。
  - 程式上現在點他應該要開聊天，但實際上點了沒反應，這個先查出原因修好（不然新按鈕也會點不到）。
- **摸頭**：換成開心的圖、冒愛心。睡覺時戳他會翻身、冒「…」。連續戳會換成難過的圖。圖都已經有了。
- **頭上冒話**：到新的位置開始做事時，有機會冒一句寫好的話（每件事 5～8 句，會看白天晚上）。3 秒後消失。
- **他留東西**：他做完某些事會留下東西，點了收下。
  - 煮完飯 → 餐桌上一盤菜（收下：少量金幣或給貓吃）。
  - 打完電腦 → 桌上一張紙條（一句話）。
  - 一天最多留 3 樣，不會一直冒。

耗電：全部是使用者點了才發生，或是跟著他原本就有的「換一件事」那個時間點，不加計時器。

### 第 2 期：家事和每日收入

- **房間會髒**：依「上次打掃的時間」算出現在有幾處髒污（碗槽的碗、地上的灰塵、滿出來的洗衣籃、浴室的水漬）。每間最多 3 處，幾個小時才多一處，最多放到滿就不再增加。
- **點髒污清掉**：每處 15～30 金幣。一天上限約 400。
- **他也會自己打掃**：房間有髒污時，他挑下一件事會多一個選項「打掃」（洗碗、掃地、收衣服、擦浴室），走到那一處、做完那一處就消失，一樣賺錢，只是比你自己點的少（每處 10～15），提示列寫「他掃完地了 +12」。
  - 你點的和他掃的共用同一個每日上限，不會因為他在掃就多賺。
  - 他不會馬上掃：髒污出現一陣子後才有機會去，留時間給你自己點；睡覺、在忙、不在家時不掃。
  - 只在小屋開著時發生。App 關著的那段時間不補算「他掃了幾處」，打開時髒污就是照時間差算出來的數量。
  - 用他原本「挑下一件事」的那個時間點，不加計時器。
- **信箱每日一封**：每天第一次打開有一封信，附 50 金幣；連續 7 天那封給 300。斷了從頭算，不補簽、不懲罰。
- **他去打工**：聊天裡他的狀態是「在忙」或「暫離」時算打工。回到家時依時間長短帶回薪水（每小時 30，一次最多 240）。用現有的狀態，不另外做系統。
- **連動現有 App**：完成一個番茄鐘、健身打卡一次，回小屋可以領 40。各一天一次。

收入的拿捏：小屋一天認真玩大約 600～900，跟刷盤子差不多。一件擺件大概是兩三天的份，不會一天買光，也不用玩一個月。

耗電：髒污是幾張靜態的小圖，數量照時間差算，不跑計時器。

### 第 3 期：養貓

- **領養**：大門點了多一個選項「領養」，第一隻免費，選花色（先做 3 種：橘、黑白、灰）。取名字。
- **貓的行為**：跟他用同一套（一次性計時器挑下一件事 + CSS 補間走路），但更懶：
  - 做的事：睡窩、窗台看外面、蹭他、吃飯、玩玩具、跟著他走。
  - 每件事 40～90 秒才換（他是 20～40 秒），七成時間是靜止的。
  - 他睡覺時貓跳上床一起睡；晚上貓大多在睡。
- **三個數值**：飽、乾淨、心情，0～100，照時間差算，約一天從滿掉到底。
  - 飽：廚房的飼料碗點了加飼料（要買）。
  - 乾淨：浴室幫牠洗澡（點幾下的小互動）。
  - 心情：摸牠、逗貓棒。
- **不照顧會怎樣**：沒精神、趴著不動、不蹭人。**不會死、不會跑、不會生病**，餵一次就恢復。這是放鬆用的，不做成壓力。
- **貓的好處**：心情高時偶爾叼東西回來（少量金幣，很少數是商店沒賣的小擺件）。一天最多 2 次。
- **圖**：每種花色要走路左右各 4 格、坐、睡、吃，約 12 張小圖。跟房間一樣用程式畫（`scripts/pixel-house/draw/`），換花色用現有的換色方法。

耗電：這期是唯一會讓畫面上多一個會動的東西的，所以門檻訂在上面「他和貓都在走」那一列。貓不用自己的換圖計時器。

### 第 3.5 期：養貓進階（2026-11-12 定案、做完）

使用者決定：
- 第一隻免費，**之後每隻都是 32,000**，最多 3 隻。
- 吃的要買：貓糧、罐頭、貓條。
- 固定開銷用**庫存自己消耗**（不自動扣錢）：貓糧和貓砂買了放著，牠們自己用，用完就餓、會在地上上廁所。
- 照顧不好會**生病，花錢看醫生**；不會死、不會跑。
- 我提的其他建議都要：個性、親密度、每月健康檢查、寵物保險、很久沒開補算、更多花色。貓跟貓互動先不做（等量測）。

省電：補算只在打開小屋、回到前景時做；開著的時候每隻貓換一件事時順便判斷生病（沒事不存檔）；想上廁所、生病的圖示是靜態的；三隻貓各一個一次性計時器，走路腳步跟他共用。

量測（CPU 放慢 4 倍，0 隻和 3 隻各跑幾次）：放著不動都是每秒醒來 0.1 次；走路 2.1～3.4 ms/秒 vs 2.1～2.8；滑房間 9.8～11.0 vs 9.5～12.5。三隻貓量不出差別，所以上限維持 3 隻。

還沒做：貓跟貓互動（擠在一起睡、互相追）。
