# 約會出門設計

## 目標

使用者和角色可以互相約出門。選一個地點，付錢，在面對面模式裡演完這場約會，結束時留下回憶卡、日記和一筆重要事件。

## 已定案

- 先做成有固定流程的小活動，不做地圖。
- 會花劇情時間。
- 角色可以主動約，也可以拒絕。
- 地點不用解鎖，不靠好感度，任何角色卡都能用。
- 誰付錢讓角色自己決定。角色付的錢從角色帳戶扣（見角色帳戶設計）。
- 有隨機事件。

## 地點

新增 `src/data/dateSpots.ts`，先放 8 個：

| 地點 | 時長 | 每人花費 |
|---|---|---|
| 咖啡廳 | 2 小時 | 150～400 |
| 電影院 | 3 小時 | 300～600 |
| 水族館 | 3 小時 | 500～900 |
| 夜市 | 3 小時 | 200～600 |
| 遊樂園 | 6 小時 | 1200～2500 |
| 海邊 | 4 小時 | 100～500 |
| 高級餐廳 | 2.5 小時 | 2000～6000 |
| 逛街 | 3 小時 | 500～3000 |

每個地點還有：圖示、一兩句氣氛描述（給 AI 用）、專屬的隨機事件。

另外有一個「自訂地點」：使用者自己輸入地點，時長預設 3 小時，花費給一個範圍讓使用者選。

## 流程

### 1. 邀約

- **使用者約角色：** 聊天工具列或主畫面的「約會」入口，選地點後送出一張邀請卡。角色下一輪回 `<date-accept/>` 或 `<date-decline reason="..."/>`。
  - 角色在睡、在忙、暫離時，照現有的暫離規則處理：邀請卡等他回來再回。
- **角色約使用者：** 角色輸出 `<date-request place="水族館" reason="..."/>`，寫法和顯示都比照現有的 `<face-to-face-request>`，使用者按答應或拒絕。
  - 提示詞只說「適合的時候可以約」，不要求頻率。
- **拒絕：** 角色可以自由拒絕，例如沒空、不想去、覺得太貴。被拒絕只留下卡片，不扣錢。

### 2. 開始

- 答應後進入面對面模式，注入約會資訊：地點、氣氛、天氣（沿用現有天氣資料）、劇情時間、這次的花費。
- 約會資料存在聊天上（`chat.dateSession`），寫法比照 `charAway`：

```ts
interface DateSession {
  id: string;
  spotId: string;
  customPlace?: string;
  startedBy: "user" | "char";
  status: "invited" | "ongoing" | "ended" | "declined";
  startedStoryTime?: number;
  durationMinutes: number;
  /** 開始時在地點範圍內抽出的總花費（兩人份） */
  cost: number;
  payer?: "char" | "user" | "split";
  event?: { id: string; text: string; injectAfterReplies: number; injected: boolean };
}
```

### 3. 付錢

- 角色在約會中輸出 `<date-pay payer="char|user|split"/>` 決定誰付。金額用開始時抽好的 `cost`，不讓 AI 自己寫數字。
- **角色付：** 扣角色帳戶。不夠就改成各付各的，並告訴角色下一輪「你的錢不夠」。
- **使用者付：** 扣使用者錢包。不夠就告訴角色。
- **一起付：** 各扣一半。
- 約會結束前角色都沒決定，就當成各付各的。

### 4. 隨機事件

- 開始時有六成機率抽一個事件。從地點專屬和共用兩張表抽，共用的例如：下雨、遇到熟人、排隊很久、忘了帶錢包、手機沒電。
- 在角色第 3 輪回覆之前，以系統提示交給 AI，例如：「突發：外面下起大雨」。
- 跟錢有關的事件會改付錢規則。例如「忘了帶錢包」：忘的人沒辦法付。

### 5. 結束

- 使用者按「結束約會」，或角色輸出 `<date-end/>`。
- **劇情時間：** 劇情時鐘模式下，往前推約會的時長，用現有劇情時鐘的寫法，可以撤銷。真實時間模式沒辦法跳時間，約會就當成現在發生的事，不推時間。
- **回憶：** 沿用禮物的回憶卡和日記做法，產生一張約會回憶卡和一篇日記。
- **重要事件：** 寫一筆重要事件，優先級 2，聊到地點或事件時才會想起。第一次約會這類重大的，交給重要事件的自動提取判斷要不要常駐。
- **偷窺手機：** 角色付的錢會出現在角色帳戶的收支紀錄。

## 介面

- 「約會」入口：地點卡片列表，每張顯示時長和大約花費。
- 邀請卡：顯示地點、誰約誰、狀態（等待中、答應、拒絕）。
- 約會中，面對面畫面上方有一條小橫幅：地點、已經過多久，旁邊是「結束約會」按鈕。

## 測試計畫

- 解析 `<date-request>`、`<date-accept>`、`<date-decline>`、`<date-pay>`、`<date-end>`。
- 付錢：角色帳戶不夠時改成各付各的；使用者不夠時有提示；沒決定時各付各的；一輪被換掉時還原。
- 隨機事件：在第 3 輪前交給 AI、只交一次。
- 結束：劇情時鐘模式推進時間並可撤銷；真實時間模式不推；產生回憶卡和重要事件。
- 回歸：`npm run type-check`、`npm run test`。
