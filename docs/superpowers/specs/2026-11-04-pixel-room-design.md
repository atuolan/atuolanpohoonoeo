# 像素房間設計

## 目標

每個角色有一間像素風的房間。房間裡有一個像素小人代表角色，動作跟著角色的狀態走。家具在商店買，送過的禮物會擺出來。使用者偶爾可以去他房間，家具會帶來不同的劇情，包括親密劇情。

## 已定案

- **小人：** 幾種固定體型，再換髮色、眼睛、膚色和衣服顏色。
- **家具：** 先放在固定位置。之後讓角色自己佈置，由 AI 決定擺設。
- 家具從商店買。送過的、不會用完的禮物會自動擺出來。
- 房間屬於角色。使用者偶爾可以去，可以觸發色色劇情。
- 有些家具會帶來不同的親密玩法，例如鏡子。
- 扭蛋可以出限定家具（扭蛋另外設計）。
- **成人內容開關：** 預設關閉。

## 位置

先做 8 個固定位置：

| 位置 | 例子 |
|---|---|
| 床 | 單人床、雙人床、圓床、帷幕床 |
| 書桌 | 木桌、電競桌、梳妝台 |
| 衣櫃 | 衣櫃、衣架 |
| 窗簾 | 各色窗簾、百葉窗 |
| 牆面 A、牆面 B | 海報、掛畫、鏡子 |
| 地毯 | 各種地毯 |
| 角落 | 盆栽、立燈、落地鏡、沙發 |
| 展示櫃 | 自動擺禮物，最多 6 格，取最新的不會用完的禮物 |

## 小人

- 2～3 種體型，每種有站著、坐著、躺著、睡覺（加 Zzz）四個姿勢。
- 髮型 6 種左右，衣服 4 套左右，顏色都可以換。
- 每個角色在房間頁設定一次，存在房間資料裡。
- 圖用程式畫：每個像素圖是一組色票加幾行字串，用 canvas 放大顯示，跟現有的 `PixelFish`、`PixelRod` 同一種做法。**美術是這個功能最花工夫的部分。**

## 小人狀態

| 角色狀態 | 小人 |
|---|---|
| 睡覺（`charAway.kind = "sleep"`） | 躺在床上，有 Zzz |
| 忙碌（`busy`） | 坐在書桌前 |
| 暫離（`away`） | 不在房間 |
| 約會中（`dateSession.status = "ongoing"`） | 不在房間，顯示「出門約會中」 |
| 其他 | 站著，偶爾走動 |

## 資料

新增 IndexedDB 表 `charRooms`，以 `characterId` 為 key，要加進備份和同步。

```ts
interface CharRoom {
  characterId: string;
  sprite: { body: string; hair: string; outfit: string; colors: Record<string, string> };
  /** 每個位置放哪件家具（商店商品 id），null 是空的 */
  placements: Record<RoomSlotId, string | null>;
  /** 買了但沒擺出來的家具 */
  storage: string[];
  lastArrangedBy?: "user" | "char";
  updatedAt: number;
}
```

## 商店

- 新增「家具」分類（`ShopCategory` 加 `"furniture"`）。
- 家具商品多一個 `roomUse` 欄位：

```ts
interface RoomUse {
  slot: RoomSlotId;
  pixelArtId: string;
  /** 一般場景提示，例如「窩在一起看電影」 */
  hint: string;
  /** 親密場景提示，只在成人內容開啟、去他房間時才送 */
  intimateHint?: string;
}
```

- 買的時候選要送給哪個角色。第一階段自動擺到對應位置，原本的家具收進 `storage`。

## 讓 AI 知道房間（省 token）

- **平常聊天：** 每個角色一筆固定 id（`room_<characterId>`）的重要事件，例如「房間：床頭放著你送的熊、牆邊有一面落地鏡」。
  - 有變動就直接改寫，不新增，所以永遠只有一行。
  - 優先級 2，配合新的重要事件規則：聊到「房間」或家具名稱時才送，平常一個字都不送。
- **去他房間：** 才把完整的家具清單和每件的場景提示交給 AI。成人內容開啟時也送親密提示。

## 去他房間

- 房間頁有「去他房間」按鈕，進入他最近一個私聊的面對面模式，開頭的系統提示寫明地點和房間擺設。
- 他在睡：場景從他睡著開始，可以叫醒，沿用睡覺和叫醒的規則。
- 他在忙：他在書桌前工作。
- 他暫離或出門約會中：按鈕停用，顯示「他不在」。

## 成人內容開關

- 全域設定，預設關閉。
- **關閉時：** 不送任何 `intimateHint`；只有親密用途的家具不出現在商店和扭蛋裡。
- **開啟時：** 去他房間才送親密提示，平常聊天不受影響。

## 分階段

1. 小人、固定位置、家具商店、禮物展示櫃、狀態姿勢、房間重要事件。
2. 去他房間、場景提示、成人內容開關。
3. 角色自己佈置：收到新家具或隔一段時間，AI 用 `<room-arrange slot="..." item="..."/>` 決定擺設；只能從他擁有的家具裡選；改完會在聊天裡提一句。
4. 扭蛋限定家具。

## 測試計畫

- 擺設：買家具自動擺到對應位置、舊的收進 `storage`；展示櫃只放不會用完的禮物、最多 6 格。
- 狀態對應：睡覺、忙碌、暫離、約會中各顯示對的姿勢。
- 房間重要事件：改寫同一筆而不是新增；平常不送，聊到「房間」或家具名稱才送。
- 成人內容：關閉時去他房間不送親密提示、商店不列只有親密用途的家具。
- 回歸：`npm run type-check`、`npm run test`。
