# 計畫表：讓錢有地方花

> 狀態（11/3 更新）：B 消耗品第一批做好了，在 `claude/care-items`，等合併。其他還沒開工。

## 問題

玩家說「錢沒地方花」。現在的經濟（`src/stores/gameEconomy.ts`，每個聊天各自一個錢包）：

- **賺錢**：刷盤子、釣魚賣魚、賭博
- **花錢**：裝飾、魚竿、背包道具、頭像框、聊天皮膚、送禮

花錢的大多是**買一次就沒了**的東西，買齊之後錢就只會一直累積。
所以重點是多做**會一直花錢的地方**；再加賺錢的遊戲，錢只會更多。

## 原則

1. **消耗品多於收藏品**：用掉就沒了，下次還要再買
2. **花錢要看得到效果**：最好能讓角色有反應，或是讓房間、小人變樣
3. **大額目標**：留幾個很貴、要存很久才買得起的東西
4. **不要懲罰**：不扣錢、不收強制費用，只給「想花」的理由

## 想法

### A. 接上像素房間（最優先，跟房間計畫一起做）

- **家具、壁紙、地板**：一定要的大宗花費，可以分稀有度
- **小人的衣服、髮型、配件**：房間和桌寵都看得到
- **房間升級**：小套房 → 公寓 → 有陽台的房子，超貴的長期目標

### B. 對角色有效果的消耗品　✅ 第一批做好（`claude/care-items`）

做好的（商城「照顧他」分頁，禮物抽屜「道具」分頁用）：

| 道具 | 價格 | 什麼時候用 | 效果 |
|---|---|---|---|
| 外帶咖啡 | 150 | 他在忙 | 馬上回你，一半機會提早忙完 |
| 能量飲料 | 400 | 他在忙 | 一定提早忙完 |
| 鬧鐘 | 120 | 他在睡 | 不用玩小遊戲；天亮後起床，天亮前只吵醒一下 |
| 愛心早餐 | 250 | 天亮後他還在睡 | 被香味叫醒起床 |
| 安眠香氛 | 300 | 晚上他醒著 | 開始覺得睏，比較會去睡 |

還沒做：點心、外送（要先有心情系統才看得到效果）；花束、小禮物原本的「送禮」就有了。

原本的想法：

| 道具 | 效果 | 接到哪個系統 |
|---|---|---|
| 咖啡、能量飲料 | 讓他提早忙完 | 忙碌（現在要擲骰） |
| 鬧鐘、早餐 | 叫他起床比較容易 | 睡覺 |
| 點心、外送 | 心情變好，小人換成吃東西的動作 | 外送、心情泡泡 |
| 花束、小禮物 | 好感度、心情泡泡 | 送禮、好感度 |
| 安眠香氛 | 讓他早點睡、睡比較好 | 睡覺 |

### C. 約會、出門

- 花錢帶他去某個地方（咖啡廳、遊樂園、海邊、旅行），越貴的地點越特別
- 去完會在聊天裡生一段劇情，或是生一張回憶卡、日記
- 旅行可以是大額目標

### D. 收集類

- **扭蛋機**：抽貼圖、小人配件、家具、回憶卡，重複的可以換碎片
- **限定商品**：節日（已經有 `holiday` store）才買得到的家具或衣服

### E. 會賺也會花的玩法（錢流動起來，不是單純變多）

- **開小店**：先花錢開店、進貨，之後慢慢回本，可以升級
- **股市、投資**：會漲也會跌，風險自己扛
- **賭博加碼**：現在已經有，可以多加幾種玩法，或是加大賭注上限

## 建議順序

1. B 消耗品：最快做，直接接現有系統，馬上就有地方花錢
2. A 家具和衣服：跟像素房間一起上
3. C 約會出門
4. D 扭蛋、E 開店和投資
