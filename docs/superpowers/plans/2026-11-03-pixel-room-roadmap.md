# 計畫表：像素小房間、2.5D、桌寵

> 狀態：只記錄想法，還沒開工。先做像素房間。

## 核心想法

把首頁變成「他的房間」。App 按鈕變成房間裡的東西，角色本人在房間裡走動，動作跟著已經有的系統變。
別人的像素世界多半只是裝飾，我們的會**真的反映角色狀態**。

## 第一優先：像素房間首頁

### 按鈕 → 房間物件

| 原本的 App | 房間裡的東西 |
|---|---|
| 聊天 | 角色本人（點他就聊天） |
| 偷看手機 | 桌上或床邊的手機 |
| 行事曆 | 牆上的月曆 |
| 書架 | 書櫃 |
| 音樂 | 音響或唱片機 |
| 遊戲中心 | 電視加遊戲機 |
| 天氣 | 窗戶（窗外跟著天氣變） |
| 商店、外送 | 門口或門鈴 |
| 設定 | 角落的小工具箱 |
| 健身 | 啞鈴或瑜珈墊 |
| 番茄鐘 | 書桌上的計時器 |
| 噗浪、QQ空間 | 電腦螢幕 |

### 角色狀態 → 房間畫面

| 已有的系統 | 房間裡看到的 |
|---|---|
| 睡覺 | 躺床上冒 Zzz，點他就進「叫他起床」 |
| 忙碌、抽空回覆 | 坐在書桌打電腦，手機偶爾亮一下 |
| 劇情時間 | 窗外白天、黃昏、晚上，房間燈光跟著變 |
| 天氣 | 窗外下雨、晴天、下雪 |
| 好感度、心情 | 表情和頭上的小泡泡（愛心、問號、生氣） |
| 健身、番茄鐘 | 換成運動或專心讀書的動作 |
| 送禮、商店 | 買的東西真的擺進房間 |

### 要注意的事

- **保留原本的首頁**：設定裡可以切換「房間模式」和「經典模式」，不要硬換掉。
- **素材**：角色用小人模板，換髮色、衣服配色，不必每個角色都畫一套。
- **效能**：用 canvas 或 CSS sprite，閒置時降低更新頻率，手機才不會燙。
- **可以重用的**：`CompanionPetWidget`（已經有成長階段、親密度）、`useWidgetCharacter`、睡覺和忙碌的狀態 store。

### 拆成小步驟

1. 靜態房間：一張像素背景，加幾個可以點的物件，點了開對應的 App
2. 角色小人站在房間裡，點他開聊天
3. 接上睡覺和忙碌狀態，切換動作
4. 窗外跟著劇情時間、天氣變
5. 心情泡泡、好感度表情
6. 送的禮物擺進房間（家具系統）
7. 可以自己擺家具、換壁紙地板

## 之後再做

### 桌寵

- 角色變成小桌寵，在**其他畫面**上也會出現（聊天、看書時在角落晃）
- 可以拖來拖去、戳他有反應、睡覺時縮成一團
- 原生 App（Capacitor）的話，研究能不能做成懸浮窗或 iOS 動態島、小工具
- 跟現有的 `CompanionPetWidget` 合併思考：寵物是角色養的，還是角色本人變小？
