# 計畫表：像素小房間、2.5D、桌寵

> 狀態：只記錄想法，還沒開工。先做像素房間。

## 核心想法

把首頁變成「他的房間」。App 按鈕變成房間裡的東西，角色本人在房間裡走動，動作跟著已經有的系統變。
別人的像素世界多半只是裝飾，我們的會**真的反映角色狀態**。

## 第一優先：像素房間首頁

### 按鈕 → 房間物件

| 原本的 App | 房間裡的東西 |
|---|---|
| 聊天 | 角色本人（點他就聊天） |
| 偷看手機 | 桌上或床邊的手機 |
| 行事曆 | 牆上的月曆 |
| 書架 | 書櫃 |
| 音樂 | 音響或唱片機 |
| 遊戲中心 | 電視加遊戲機 |
| 天氣 | 窗戶（窗外跟著天氣變） |
| 商店、外送 | 門口或門鈴 |
| 設定 | 角落的小工具箱 |
| 健身 | 啞鈴或瑜珈墊 |
| 番茄鐘 | 書桌上的計時器 |
| 噗浪、QQ空間 | 電腦螢幕 |

### 角色狀態 → 房間畫面

| 已有的系統 | 房間裡看到的 |
|---|---|
| 睡覺 | 躺床上冒 Zzz，點他就進「叫他起床」 |
| 忙碌、抽空回覆 | 坐在書桌打電腦，手機偶爾亮一下 |
| 劇情時間 | 窗外白天、黃昏、晚上，房間燈光跟著變 |
| 天氣 | 窗外下雨、晴天、下雪 |
| 好感度、心情 | 表情和頭上的小泡泡（愛心、問號、生氣） |
| 健身、番茄鐘 | 換成運動或專心讀書的動作 |
| 送禮、商店 | 買的東西真的擺進房間 |

### 要注意的事

- **保留原本的首頁**：設定裡可以切換「房間模式」和「經典模式」，不要硬換掉。
- **素材**：角色用小人模板，換髮色、衣服配色，不必每個角色都畫一套。
- **效能**：用 canvas 或 CSS sprite，閒置時降低更新頻率，手機才不會燙。
- **可以重用的**：`CompanionPetWidget`（已經有成長階段、親密度）、`useWidgetCharacter`、睡覺和忙碌的狀態 store。

### 拆成小步驟

1. 靜態房間：一張像素背景，加幾個可以點的物件，點了開對應的 App
2. 角色小人站在房間裡，點他開聊天
3. 接上睡覺和忙碌狀態，切換動作
4. 窗外跟著劇情時間、天氣變
5. 心情泡泡、好感度表情
6. 送的禮物擺進房間（家具系統）
7. 可以自己擺家具、換壁紙地板

## 之後再做

### 2.5D 斜角房間

- 像素版穩了以後，做一個斜 45 度的精緻版當「另一種房間皮膚」
- 物件和狀態的對應表跟像素版共用，只換畫面

### 桌寵（已決定：角色本人變小）

- 角色本人縮小，在**其他畫面**上也會出現（聊天、看書時在角落晃）
- 可以拖來拖去、戳他有反應、睡覺時縮成一團
- 原生 App（Capacitor）的話，研究能不能做成懸浮窗或 iOS 動態島、小工具
- `CompanionPetWidget` 的親密度、成長階段可以拿來參考，但主角是他本人

## 共用的小人動作表

房間和桌寵用**同一套小人、同一套動作**，畫一次兩邊都能用。

### 身體動作（固定的 sprite 動畫）

| 動作 | 什麼時候出現 | 優先 |
|---|---|---|
| 待機（呼吸、眨眼） | 沒事的時候 | ★ 第一批 |
| 走路 | 在房間裡閒晃、換位置 | ★ 第一批 |
| 睡覺（縮成一團、Zzz） | 睡覺系統 | ★ 第一批 |
| 滑手機／打電腦 | 忙碌、抽空回覆 | ★ 第一批 |
| 被戳（嚇一跳） | 使用者點他 | ★ 第一批 |
| 被拎起來（腳晃晃） | 桌寵被拖動 | 第二批 |
| 打哈欠 | 快到睡覺時間 | 第二批 |
| 開心跳跳 | 收到禮物、好感度上升 | 第二批 |
| 看書 | 書架、番茄鐘 | 第三批 |
| 運動 | 健身 | 第三批 |
| 吃東西 | 外送到了 | 第三批 |

### 心情泡泡（疊在頭上，跟身體動作分開）

愛心、音符、問號、汗滴、生氣、害羞紅暈、Zzz、「…」

**分開的好處**：身體動作 × 心情泡泡可以自由組合（例如「滑手機＋愛心」＝在偷傳訊息給你），不用每種組合都畫一張。

### 狀態怎麼決定

1. **系統狀態優先**：睡覺、忙碌、健身、番茄鐘這些一定是對的，直接用
2. **心情從聊天來**：之後可以讓模型在回覆時順便給一個心情標籤（開心、生氣、害羞…），換成泡泡
3. **都沒有的時候**：待機和走路隨機輪流，偶爾打哈欠、伸懶腰

### 素材做法

- 一個基本小人模板（例如 32×32 或 48×48 像素），每個動作 2 到 6 格
- 髮型、髮色、衣服用換色或換零件，不用每個角色重畫
- 之後可以開放使用者上傳自己的 sprite sheet
